# АЮ READY КВИЗ — ответы и команды

Ответы на 7 туров (по 7 вопросов) и список команд с числом игроков.
Сохраняется автоматически: на сервере (`data/state.json`) и копией в браузере.

## Запуск на Render
- New → Web Service → подключить этот репозиторий
- Build Command: `npm install`
- Start Command: `npm start`
- Instance Type: Free

## Про сохранение
На бесплатном Render файл на сервере стирается при перезапуске.
Поэтому каждый браузер хранит свою последнюю копию и сам отправляет её
обратно на сервер, если там данных нет или они старее.
Для надёжности есть кнопки «Скачать копию» / «Загрузить копию».
